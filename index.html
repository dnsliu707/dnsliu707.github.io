01 · Single-cell agents

Agents that read the tumor microenvironment.

At the Xia Lab I am building an autonomous, LLM-powered agent system for cancer single-cell analysis. It plans multi-step analyses, tests hypotheses iteratively and runs analysis tools on its own.

  • AnnotationA cell-type annotation agent that pairs biological knowledge retrieval with multi-step reasoning to characterize rare, transitional and malignant cells.
  • DiscoveryA reasoning agent for oncogenic gene discovery that infers cell–cell communication, functional gene perturbations and pathway shifts.

02 · Explainable reasoning

Every conclusion traces back to evidence.

An explainable-AI layer records each agent decision and tool call, then links it to verifiable biological evidence. A gene signature should arrive with its rationale.

  • TraceabilityDecision paths and tool executions mapped to the evidence that supports them.
  • BenchmarksReasoning fidelity, tool-use precision, self-reflection loops and hallucination rates, measured against expert-curated genomic datasets.
